# Project-local Skills

이 폴더는 Jabin 저장소에서 공동으로 사용하는 에이전트 Skill을 보관한다. 개인 전역 설정과 분리되어 Git으로 함께 버전 관리할 수 있다.

## design-taste-frontend

- 원본: `Leonxlnx/taste-skill`의 `skills/taste-skill`
- 설치 위치: `.agents/skills/design-taste-frontend`
- 원본 규칙: `SKILL.md`
- Jabin 적용 규칙: `JABIN_PROFILE.md`

업데이트할 때는 원본 `SKILL.md`를 먼저 교체한 뒤 `JABIN_PROFILE.md`의 예외와 충돌 여부를 검토한다. 원본 Skill 파일에 프로젝트 전용 규칙을 직접 섞지 않는다.
